# Multi-Omics Integration for Breast Cancer Molecular Subtype Classification 

- Problem Statement: Investigating whether integrating multiple molecular data types—gene expression, copy number variation (CNV), and somatic mutations—improves the classification of breast cancer molecular subtypes compared with using gene expression alone.

- Impact: Improved molecular subtype classification could support a better understanding of breast cancer molecular profiles and demonstrate the value of multi-omics data integration in computational cancer research.

- Scope: Develop and evaluate machine learning models using the Moanna METABRIC and TCGA-BRCA datasets to classify four PAM50 subtypes (Basal-like, HER2-enriched, Luminal A and Luminal B). The project includes data exploration, dimensionality reduction, unsupervised learning, and supervised classification.
